# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Zenqo, please report it responsibly.

**Do not open a public issue.**

Instead, email security concerns to the maintainer or use [GitHub's private vulnerability reporting](https://github.com/zenqos/zenqo/security/advisories/new).

We will respond within 72 hours and work with you to understand and address the issue.

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
